# ケーキでピッタリ！

足して「1」になる分数のペアをさがす、神経衰弱形式の分数学習ゲームです。

[🎮 今すぐ遊ぶ](https://sr-econ04.github.io/fraction-puzzle/)

## ゲームの概要

「たし算で1になる分数」を見つける感覚を、遊びながら身につけられる学習ゲームです。

カードを2枚めくり、足して「1」になる分数のペアを見つけるとケーキが完成します。
すべてのケーキを完成させればクリアです。
小学校低学年でも取り組みやすいよう、絵文字を使わずシンプルな配色・大きな文字・ふりがな付きで構成しています。

## あそびかた

1. 「ペアの数」から **3ペア / 5ペア / 8ペア** のいずれかを選び、難易度を決める
2. 「スタート」を押してゲームを開始する
3. カードを2枚タップしてめくる
4. 足して「1」になる分数のペアならケーキが完成する
5. すべてのケーキを完成させたらクリア（クリアまでの時間が記録として表示される）

外れた場合はカードが自動で元に戻り、何度でもチャレンジできます。

初めての方は「れんしゅう」ボタンから、ヒント付きのチュートリアル（やってみよう → ガイドつき練習 → 自由に練習）でルールを学べます。

## あそべる分数の組み合わせ

| 分数A | 分数B |
| :---: | :---: |
| 1/2 | 1/2 |
| 1/3 | 2/3 |
| 1/4 | 3/4 |
| 1/5 | 4/5 |
| 1/6 | 5/6 |
| 2/5 | 3/5 |
| 1/8 | 7/8 |
| 3/8 | 5/8 |

選んだペア数に応じて、この中からランダムに組み合わせが選ばれます。

## 対象

小学校低学年（分数の基礎を学ぶお子さま）

## 工夫した点

- 絵文字を使わず、色数を抑えた配色（空色・コーラル・砂色・ミントの4色ベース）
- カードの色はペアごとに同じ色にならないようシャッフルし、色だけで答えが分からないようにしている
- カード枚数や画面サイズに応じてグリッドの列数を自動調整し、PC・スマートフォンどちらでも見やすいレイアウトになる
- 判定中・演出中・正解表示中は操作をロックし、連打による表示崩れを防止
- ペアが完成すると、数式（例: 1/2 + 1/2 = 1）を読みやすい画面で表示
